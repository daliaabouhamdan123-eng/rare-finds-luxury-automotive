Overview
Rare Finds is a luxury automotive website showcasing a curated collection of exotic and race cars. The digital experience combines an editorial visual style with vehicle-focused browsing, photography, and detailed galleries.
The goal was to create a refined online showroom that lets each vehicle take center stage while keeping navigation clear and responsive across devices.
My Role
UI/UX Design · Web Design · Front-End Implementation · Deployment
I worked on the website's visual direction, page structure, vehicle presentation, responsive experience, and publishing workflow, using AI-assisted development tools as part of the process.
Highlights
- Premium, image-led design for a luxury automotive audience
- Vehicle collections organized for easier browsing
- Individual vehicle photography and gallery experiences
- Dedicated presentation of exotic cars and motorsport content
- Responsive layouts for desktop and mobile
- Search-engine foundations, including metadata and indexing setup
Tools & Technologies
- HTML, CSS, and JavaScript
- AI-assisted development with Claude
- Cloudflare Pages for deployment
- Cloudflare R2 for media storage
- Google Search Console for search visibility
Design Approach
Visual storytelling first. Large automotive photography and restrained typography help communicate the character of each vehicle.
Clarity without clutter. Vehicle information and navigation support browsing without distracting from the collection.
Performance-conscious media. Hosted image assets and selective loading strategies help manage a photography-heavy experience.
